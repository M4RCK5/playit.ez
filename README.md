## playit.ez
Batch script to quickly setup a playit agent.

### Install
[Download the script](/archive/refs/heads/main.zip) and launch it.

Note: to auto-start the script with windows add it to "shell:startup".

#### Launch Parametters
```
 -h  Show all launch parameters.
 -d  Open web dashboard.
 -f  Open playit.ez folder.
 -s  Stop playit.ez.
 -r  Reset playit.ez proxy settings.
 -u  Update playit.ez.
 -w  Wipe all playit.ez files.
```

### Dependencies
 - [playit.gg](https://github.com/playit-cloud/playit-agent/)
